# YOLO Object Detection using Python

A real-time **object detection system** built using **Python, OpenCV, YOLO, and CVZone**. The project uses a webcam to detect and identify objects in real time, displaying their bounding boxes, class names, and confidence scores.

## Technologies Used

* **Python**
* **YOLO (Ultralytics)**
* **OpenCV**
* **CVZone**

## Future Improvements

* Count detected objects
* Save detection results
* Detect objects from uploaded videos
* Add custom-trained YOLO models
* Add alerts for specific objects
